# Store Listing Translations

The store listing in every locale the package ships, for stores that ask for a listing per language. Opera, for one, takes its language list from the package's `_locales` and wants a Summary and a Description in each language, not English. One section per shipped locale, for version 1.1.0.

- Summary: the locale's `extDescription` from the package; stores that read the manifest fill it in on their own.
- Description: a shorter version of the English listing in `store-listing-copy.md`, with the public-log disclosure kept.
- Changelog: the 1.1.0 release notes, without the Firefox-only item.
