# Support

- **Using Emojery** — the [FAQ](https://emojery.app/faq?utm_source=github&utm_medium=support&utm_campaign=emojery&utm_content=faq) covers supported sites, how counts work, and privacy; anything it doesn't, ask in a [question issue](https://github.com/khasky/emojery/issues/new?template=question.md).
- **Something broken on a page** — use the extension's Report tab (toolbar popup → Report) for page-specific problems, or open a [bug report](https://github.com/khasky/emojery/issues/new?template=bug_report.md).
- **Want a site supported** — check the [roadmap](https://emojery.app/roadmap?utm_source=github&utm_medium=support&utm_campaign=emojery&utm_content=roadmap) first, then open a [site request](https://github.com/khasky/emojery/issues/new?template=site_request.md).
- **A privacy question, a data request, or a legal notice** — open a [privacy or legal issue](https://github.com/khasky/emojery/issues/new?template=privacy_legal.md). What the extension sends is in [docs/permissions.md](docs/permissions.md) and at [emojery.app/privacy](https://emojery.app/privacy?utm_source=github&utm_medium=support&utm_campaign=emojery&utm_content=privacy); keep personal data out of the public thread.
- **Security problems** — never in a public issue: [open a private security advisory](https://github.com/khasky/emojery/security/advisories/new). See [SECURITY.md](SECURITY.md).

Contributing code instead? Start with [CONTRIBUTING.md](CONTRIBUTING.md).
